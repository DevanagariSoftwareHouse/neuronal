# Source-backed MATLAB code in the book

The textbook includes actual `.m` files using `\\lstinputlisting`.
The canonical executable demonstrations live in `../../examples/matlab/`,
and method implementations stay in `../../../matlab/path/`. No pasted
independent code copies should appear in the LaTeX sources.

A book chapter may refer to MATLAB as a numerical object, but only
this volume embeds MATLAB code. Formal Lean source belongs exclusively
to the formal-foundations volume.
